# Полная beta-версия в заголовке

Утверждено владельцем 15.09.2026: в центральной плашке показывается версия UI с учётом беты.

Формат строки: `UI vMAJOR.MINOR.PATCH-betaNNN`. Между `beta` и трёхзначным номером точки нет. В стабильной версии суффикс отсутствует.

Номер UI и номер интеграции остаются независимыми; суффикс beta-сборки должен совпадать. Для этой публикации: интеграция `1.1.2-beta004`, строка заголовка `UI v1.1.5-beta004`.

Полная версия UI используется согласованно в production-модуле, `PANEL_VERSION`, метаданных панели, `.nikas-ui-standard.json` и параметрах загрузки интерфейса/ассетов. Нельзя отрезать суффикс в отрисовке или заменять beta-релиз номером стабильной версии.

Это узкое уточнение требования к строке версии из UI Standard 2.2 и Header Contract 1.18. Общие закреплённые документы и их контрольные суммы не изменены. Остальные требования, включая сохранение геометрии, чёрную стрелку в обычном состоянии и точечное обновление DOM, остаются в силе.

Проверки: `python3 tests/test_release_version_display.py` и `node scripts/check-header-release-version.mjs`. Проверяются полный текст версии, соответствие метаданных и отсутствие обрезания в центральной плашке на мобильных и настольных размерах.
