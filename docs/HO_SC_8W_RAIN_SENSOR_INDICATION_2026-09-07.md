# HO-SC-8W: датчик дождя и индикация блокировки

## Подтверждено пользователем 07.09.2026

- Зона с включённым учётом датчика дождя блокирует полив при срабатывании.
- Зона с выключенным учётом датчика поливает независимо от него.
- Время высыхания датчика пока не измерено; это открытый вопрос.
- Расписание по дням недели ранее проверено на приборе, повторять эту
  проверку в рамках исследования дождя не требуется.

Это подтверждение поведения со слов пользователя, а не новый протокол
записи DP38 или захват пакетов при намокании/высыхании датчика.

## Что обнаружено в родном приложении

Проверен ранее сохранённый INKBIRD 2.1.11, пакет
`com.inkbird.inkbirdapp`, именно модуль `/device/iic800/`.
Это протокольный референс для HO-SC-8W: отсутствие элемента в нём не
доказывает его отсутствие во всех версиях приложений или Tuya-панелей.

Источник повторной проверки — прямое чтение `classes14.dex` Androguard
4.1.4 и сопоставление констант ресурсов с `resources.arsc`:

- APK SHA-256: `ab276f1bf350ba8569a3ec5f48fafced49cbdff621fd15586422e34397b5c946`.
- DEX SHA-256: `09461bde9f57cb36d3c7cd1bb2aba3236a12a81665589462c3554335a34ffe42`.

| Место в коде | Что фактически делает |
|---|---|
| `Iic800SettingsModel.getRainSenTotal` | Читает DP102 как Boolean. |
| `Iic800SettingsPresenter.changeRainSensor` | Отправляет в DP102 инверсию текущего значения. Это общий выключатель учёта датчика. |
| `Iic800SettingsActivity.setRainSenTotal` | Обновляет изображение переключателя настройки. |
| `Iic800AddPlanActivity` | Предлагает Obey/Ignore для зоны; `showRainSensorDialog` показывает сообщение о выключенном общем переключателе. |
| `Iic800Presenter.onDpUpdate` | При DP102 обновляет `TotalSeaSwitch` у зон; `deviceAlarm` вызывается по DP106. Отдельной ветви состояния мокрого датчика не найдено. |
| `Iic800Activity.setNextTimeInfo` | Показывает текущий/следующий полив, время старта, остаток и выключенное питание. Сообщения о дождевой блокировке в методе не найдено. |
| `WateringHistoryAdapter.onBindViewHolder` | Показывает время старта и длительность из разности end/start; причину дождевого пропуска не выводит. |

Проверенные строковые ресурсы:

- `iic800_rain_sensor`: Main Switch Of Rain Sensor.
- `iic800_obey_rain_sensor`: Obey or Ignore Rain Sensor?
- `iic800_rain_sensor_switch_tips`, ID `2132021927`: сообщение о выключенном
  общем переключателе, а не о намокании датчика.

В общих ресурсах APK есть `dev_text_rain_sensor_skip_toast` и строки
Rain delay. В проверенном модуле IIC-800 их использование не найдено;
наличие общей строки само по себе не подтверждает функцию у этого прибора.

## Следствие для нашей панели

`HOSC8WRainSensorState` сейчас публикует enabled/disabled из
`device.rain_sensor_enabled` (DP102); `rainPresentation` подписывает это
«Учитывается / Не учитывается». Сигнала «мокрый / сухой» в этой сущности нет.
Не следует превращать DP102=true в «блокировка дождём» либо «дождя нет».
Отсутствие активных зон тоже не устанавливает причину остановки.

Чтобы добавить достоверную индикацию и измерение времени высыхания,
нужен сравнительный захват фактических входящих DP при сухом датчике,
его срабатывании и восстановлении, при неизменных настройках учёта.
Если отдельного сигнала в протоколе нет, понадобится независимое
наблюдение контакта. Время высыхания измеряется от окончания намокания
до восстановления контакта; ожидание очередного запуска по расписанию
не равно времени высыхания. Автоматическое измерение пока не реализовано.

## Внешний вид UI 0.7.08

По просьбе пользователя большой блок с изображением контроллера при
нормальном состоянии получает обычный фон и нейтральную рамку.
Зелёная подсветка отдельной плашки давления сохраняется. Предупреждения,
аварийные состояния и отсутствие данных сохраняют прежнее оформление.
Правило применяется после точечных обновлений, в том числе при переходе
из аварии обратно в норму; команды контроллеру не изменены.
