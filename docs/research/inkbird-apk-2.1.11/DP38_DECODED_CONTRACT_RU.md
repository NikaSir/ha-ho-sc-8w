# HO-SC-8W / INKBIRD IIC-800 — расшифрованный контракт DP38

Статус: исследовательский документ. Основан на точном smali INKBIRD 2.1.11 и сопоставляется с натурными DP38 HO-SC-8W. Production-запись DP38 остаётся заблокированной до контролируемого read-back теста.

## 20-байтовый блок

| byte | значение |
|---:|---|
| 0 | при чтении: номер зоны 1..8; при записи: one-hot маска 01,02,04,08,10,20,40,80 |
| 1 | runTime, минуты |
| 2..7 | часы шести стартов |
| 8..13 | минуты шести стартов |
| 14 | scheduleMode |
| 15 | scheduleDay / параметр режима |
| 16 | intervalYear, YY |
| 17 | intervalMonth |
| 18 | intervalDay |
| 19 high nibble | Enable: 1/0 |
| 19 low nibble | SeaAdjSwitch в Java-модели; по экрану IIC-800 это Obey/Ignore Rain Sensor: 1/0 |

Неиспользуемый старт представлен парой FF/FF.

## scheduleMode — подтверждено UI bytecode

- 0 — Weekly.
- 1 — Odd days.
- 2 — Even days.
- 3 — Interval.

Для Weekly экран вызывает `WeekAdapter.getChecks()` и результат без преобразования кладёт в `scheduleDay`.

Для Interval экран кладёт в `scheduleDay` числовое значение интервала, введённое пользователем. Поля YY/MM/DD хранят дату-якорь.

## Weekly mask

Подтверждено:

- `scheduleDay` — семибитная маска;
- `7F` означает все семь дней (такое значение используется и в заводском reset-пакете);
- конкретное соответствие битов Пн..Вс ещё должно быть извлечено из `WeekAdapter.getChecks()/setChecks()` и не считается доказанным.

До этого нельзя делать production-энкодер недельных дней по предположению о порядке битов.

## Последний байт

APK строит байт 19 как два ASCII-hex полубайта:

- `isEnable() ? "1" : "0"`;
- `isSeaAdjSwitch() ? "1" : "0"`.

По ресурсам экрана второй флаг относится к `Obey or Ignore Rain Sensor`, а глобальная сезонная коррекция хранится отдельно в DP103.

Следовательно структурно допустимы:

- 11 — программа включена, obey rain sensor;
- 10 — программа включена, ignore rain sensor;
- 01 — программа выключена, obey rain sensor;
- 00 — программа выключена, ignore rain sensor.

Комбинации 01/00 пока не подтверждены натурным read-back HO-SC-8W.

## Дата-якорь

Штатный reset использует хвост `...00 7F 15 09 01 01`, что соответствует YY=0x15, MM=0x09, DD=0x01, то есть 2021-09-01. Это подтверждает порядок YY/MM/DD и отсутствие дополнительного смещения года кроме стандартного +2000 при отображении.

## Безопасность записи

1. Писать только один 20-байтовый блок зоны.
2. В byte0 использовать one-hot selector, не номер зоны.
3. После записи ожидать read-back, где byte0 снова будет обычным номером зоны.
4. Сравнивать байты 1..19 и одновременно проверять, что остальные зоны не изменились.
5. Не включать недельную запись, пока не доказан порядок битов WeekAdapter.
6. Не включать production DP38 write автоматически после рестарта/таймаута.
