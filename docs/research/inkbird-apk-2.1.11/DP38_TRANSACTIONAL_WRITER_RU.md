# HO-SC-8W — транзакционная запись DP38

Статус: research-only. Физическая production-запись DP38 не разблокирована.

## Цель

Не пересобирать 20-байтовую программу зоны «с нуля», а всегда начинать со свежего блока, прочитанного с контроллера, и менять только явно выбранные пользователем поля.

## Этап 1 — dry-run

1. Получить свежий 20-байтовый READ-блок нужной зоны.
2. Проверить обычный идентификатор зоны в byte0: `01..08`.
3. Построить минимальный patch поверх точной копии исходного блока.
4. Преобразовать byte0 только для WRITE: `01,02,04,08,10,20,40,80`.
5. Рассчитать ожидаемый read-back, где byte0 снова обычный номер зоны.
6. Показать точный diff по байтам и декодированным полям.
7. Dry-run не выполняет сетевых обращений и не отправляет команд.

## Этап 2 — будущая подтверждённая запись

Перед физической отправкой writer обязан:

1. Получить новый свежий READ-блок этой же зоны.
2. Сравнить его byte-for-byte с `source_read` подготовленной транзакции.
3. Если блок изменился — отменить транзакцию; автоматическая пересборка и повтор запрещены.
4. Убедиться, что полив и очередь не активны.
5. Отправить ровно один 20-байтовый DP38 String payload в uppercase HEX.
6. Выполнить bounded read-back.
7. Требовать точного совпадения байтов 1..19 с `expected_read`.
8. Проверить, что остальные зоны не изменились.

Любое несовпадение считается неуспешной транзакцией и требует ручной диагностики. Автоматический retry DP38 запрещён.

## Реализовано

- `dp38_patch.py` — консервативное изменение только явно заданных полей.
- `dp38_transaction.py` — immutable dry-run transaction plan, byte diff и exact read-back verifier.
- `scripts/check-dp38-transaction.py` — pure contract tests без Home Assistant, сети и контроллера.

## Пример

Исходный READ зоны 8:

```text
081E05FFFFFFFFFF00FFFFFFFFFF002A1A090411
```

Пользователь меняет только `rain_sensor_follow: true -> false`.

WRITE:

```text
801E05FFFFFFFFFF00FFFFFFFFFF002A1A090410
```

Ожидаемый READ:

```text
081E05FFFFFFFFFF00FFFFFFFFFF002A1A090410
```

Diff:

- byte0: `08 -> 80` — только преобразование READ/WRITE selector;
- byte19: `11 -> 10` — только Obey/Ignore Rain Sensor.

Байты 1..18 остаются идентичными.
